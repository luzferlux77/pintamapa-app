# PintaMapa · actualizaciones

Repositorio de publicación de **PintaMapa**, el juego de pintar las calles de tu ciudad andando.

* `app.json`: última versión publicada. La app la consulta para actualizarse sola.
* **Releases**: paquete web (actualización en caliente) y APK firmada de cada versión. Se conservan las 3 últimas.

Mapas y calles © colaboradores de OpenStreetMap.
